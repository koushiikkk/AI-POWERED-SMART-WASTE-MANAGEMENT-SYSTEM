---
name: Backend
description: Rules for FastAPI backend development.
---

- Python + FastAPI
- REST resource-oriented endpoints
- Pydantic validation
- correct HTTP status codes
- routers separated by resource
- business/smart logic in separate modules
- parameterized SQL
- CORS restricted to frontend origin where practical
- environment variables
- clear error responses
- no hardcoded credentials
- backend must be testable through Postman
- do not hide errors
